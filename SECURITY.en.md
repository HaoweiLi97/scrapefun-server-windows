# Security reporting

[简体中文](./SECURITY.md) · **English**

> Updated: 2026-09-28

Report vulnerabilities privately to `scrapefun@outlook.com` with the subject `ScrapeFun Security`. Include platform, affected versions, impact, and reproduction materials with sensitive information removed. Do not publish exploitation details for unfixed vulnerabilities or user credentials in public issues.

See the [main security information](https://github.com/HaoweiLi97/ScrapeFun/blob/main/SECURITY.en.md) for the full process, deployment boundaries, and download verification instructions.
